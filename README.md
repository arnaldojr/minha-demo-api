# API do Assistente de Cursos

API construída com FastAPI para conversar com um assistente de organização de estudos.

## Como executar

1. Crie um ambiente virtual com `python -m venv .venv`.
2. Ative o ambiente virtual de acordo com seu sistema operacional.
3. Instale as dependências com `pip install -r requirements.txt`.
4. Crie o arquivo `.env` com base em `.env.example` e informe uma chave válida.
5. Inicie a aplicação com `fastapi dev main.py`.
6. Acesse `http://127.0.0.1:8000/docs`.
